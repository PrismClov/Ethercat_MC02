# EtherCAT ↔ FDCAN 数据格式（17 轴 · 达妙 MIT）

> 适用固件：`User/EtherCAT` + `User/Start/Src/WHW_IRQN.c`
> 对象字典由 `User/SSC/SSC_Device.esp` 经 SSC 工具生成
> 最后核对：2026-10-26

---

## 1. 系统结构

```
上位机 ── EtherCAT 100M ── LAN9252 ── SPI 40MHz ── STM32H723
                                                      │
                                        ┌─────────────┼─────────────┐
                                     FDCAN1         FDCAN2        FDCAN3
                                     7 轴           7 轴          3 轴
                                    (左臂)         (右臂)       (独立)
```

| 项 | 值 |
|---|---|
| 从站 | STM32H723 + LAN9252（SPI PDI，40 MHz） |
| 输出 PDO | 196 B（主站 → MCU） |
| 输入 PDO | 416 B（MCU → 主站） |
| SM2 / SM3 | 196 B / 416 B（EEPROM SII 里就是这个值，未改动） |
| 控制周期 | SYNC0 500 µs ~ 4 ms（实测 2 kHz / 3 kHz 稳定，1 kHz 余量最大） |
| CAN 发送 | TIM7 1 ms 固定节拍 |
| 字节序 | 全部小端 |

## 2. 输出 PDO（主站 → MCU）196 B

| 偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0 | 1 B | 控制字 | 见 2.1 |
| 1 | 3 B | 序列号 | LE24，每周期 +1，溢出回绕 |
| 4 | 170 B | 17 轴命令 | 每轴 10 B，`偏移 = 4 + (n-1)×10` |
| 174 | 2 B | 填充 | 置 0 |
| 176 | 20 B | `0x7050` | U1..U20，见 2.3 |

### 2.1 控制字位定义

| 位 | 含义 |
|---|---|
| bit0 | 全局使能 |
| bit1 | 急停（MCU 立即下发零力矩、零增益 MIT 帧） |
| bit2 | 回零 |
| bit3~7 | 模式：0=MIT 阻抗，1=纯位置，2=纯速度，3=纯力矩，其余保留 |

### 2.2 单轴命令槽（10 B）

| 槽内偏移 | 字段 | 类型 | 编码 |
|---|---|---|---|
| +0 | 目标位置 | INT16 | 1 LSB = 0.01° |
| +2 | 目标速度 | INT16 | 1 LSB = 0.1°/s |
| +4 | 力矩前馈 | INT16 | 1 LSB = 0.01 A |
| +6 | Kp | UINT16 | 物理值 0~500，直接写 |
| +8 | Kd | UINT16 | 0.01 定点，250 = Kd 2.50 |

### 2.3 `0x7050` 扩展区（20 B）

| 偏移 | 字段 | 用途 |
|---|---|---|
| 176 | U1 | WS2812 的 R |
| 177 | U2 | WS2812 的 G |
| 178 | U3 | WS2812 的 B |
| 179~194 | U4..U19 | 保留，置 0 |
| 195 | U20 | bit0 = 1 用 U1/U2/U3 控制灯；= 0 回落到状态灯（绿=使能，红=急停，灭=未使能） |

> **延迟探针占用**：U4..U7（偏移 180~183）= 主站时间戳低 32 位（µs，
> `now_us()` 的小端 uint32）。从站原样回显到输入 `VT1..VT4`。

## 3. 输入 PDO（MCU → 主站）416 B

| 偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0 | 12 B | IMU | 见 3.1 |
| 12 | 170 B | 17 轴反馈 | 每轴 10 B，`偏移 = 12 + (n-1)×10` |
| 182 | 21 B | VT1..VT21 | 额外遥测（USART7 透传） |
| 203 | 1 B | end1 | 置 0 |
| 204 | 212 B | `0x60F0` | R1..R212（USART1 透传） |

> **延迟探针占用 VT1..VT8**（固件 `PDO_LATENCY_PROBE=1` 时）：
>
> | 偏移 | 字段 | 类型 | 含义 |
> |---|---|---|---|
> | 182 | VT1..VT4 | UINT32 | 回显主站写入的 `0x7050 U4..U7` 时间戳 |
> | 186 | VT5..VT6 | UINT16 | PDI 中断执行时间（µs，**纯 MCU，不含 Windows**） |
> | 188 | VT7..VT8 | UINT16 | 输出事件 → 输入映射 的相位差（µs，含 SYNC0 等待） |
>
> 这 8 B 会覆盖 USART7 透传的数据；若要同时用 USART7，把固件里的
> `PDO_LATENCY_PROBE` 置 0。
>
> **两种延迟口径**：
> - `RTT = 主站收到回显时刻 − 主站写入时间戳时刻`，**含 Windows 调度**；
>   由于回显要等下一个 SYNC0 才发布，基线约等于 1 个 SYNC0 周期（2 kHz 下 ~500 µs）。
> - `MCU 处理 = PDI 中断耗时`，**不含 Windows 调度**，实测 15 µs。

### 3.1 IMU（12 B）

| 偏移 | 字段 | 类型 | 换算 |
|---|---|---|---|
| 0 | AX | INT16 | `× 0.00179443359375` → m/s²（**不是 g**，静止约 9.81） |
| 2 | AY | INT16 | 同上 |
| 4 | AZ | INT16 | 同上 |
| 6 | GX | INT16 | `× 0.00106526443603` → rad/s |
| 8 | GY | INT16 | 同上 |
| 10 | GZ | INT16 | 同上 |

> 量程：加速度 ±6 g，陀螺 ±2000 dps。
> 温度不在 PDO 里（`BMI088_RawInfo_Update` 会写 14 B，固件用临时缓冲区
> 只拷前 12 B，温度留在 `dbgImuTemp`）。

### 3.2 单轴反馈槽（10 B）

| 槽内偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| +0 | ID1 | UINT8 | 电机 ID 低字节 |
| +1 | ID2 | UINT8 | 高字节，`ID = ID1 \| (ID2<<8)` |
| +2 | 实际位置 | INT32 | 1 LSB = 0.01° |
| +6 | 实际速度 | INT16 | 1 LSB = 0.1°/s |
| +8 | 状态字 | UINT16 | 见 3.3 |

### 3.3 状态字位定义

| 位 | 含义 |
|---|---|
| bit0 | 使能 |
| bit1 | 故障 |
| bit2 | 到位 |
| bit3 | 限位触发 |
| bit4 | 回零完成 |
| bit5 | **反馈有效**（本周期收到反馈 = 1，超时/丢帧 = 0） |
| bit6~15 | 保留，置 0 |

## 4. 轴号与偏移

`命令偏移 = 4 + (n-1)×10`，`反馈偏移 = 12 + (n-1)×10`

| 总线 | 轴 | 槽位 | 命令偏移 | 反馈偏移 |
|---|---|---|---|---|
| CAN1 | 1~7 | A..G | 4, 14, 24, 34, 44, 54, 64 | 12, 22, 32, 42, 52, 62, 72 |
| CAN2 | 8~14 | A..G | 74, 84, 94, 104, 114, 124, 134 | 82, 92, 102, 112, 122, 132, 142 |
| CAN3 | 15~17 | A..C | 144, 154, 164 | 152, 162, 172 |

## 5. FDCAN 帧格式

### 5.1 下行：MIT 命令帧（MCU → 电机）

标准帧，11 位 ID = 电机 `motor_id`，DLC = 8。

| 字节 | 内容 |
|---|---|
| `D[0]` | `pos_u[15:8]` |
| `D[1]` | `pos_u[7:0]` |
| `D[2]` | `vel_u[11:4]` |
| `D[3]` | `vel_u[3:0] << 4 \| kp_u[11:8]` |
| `D[4]` | `kp_u[7:0]` |
| `D[5]` | `kd_u[11:4]` |
| `D[6]` | `kd_u[3:0] << 4 \| tor_u[11:8]` |
| `D[7]` | `tor_u[7:0]` |

量化：

```c
pos_u = float_to_uint(pos_rad, -PMAX, PMAX, 16);
vel_u = float_to_uint(vel_rad, -VMAX, VMAX, 12);
tor_u = float_to_uint(tor_nm,  -TMAX, TMAX, 12);
kp_u  = (uint16_t)(clamp(kp, 0, 500) * 4095.0f / 500.0f + 0.5f);
kd_u  = (uint16_t)(clamp(kd, 0,   5) * 4095.0f /   5.0f + 0.5f);
```

PDO → 物理量：

- 位置 `度 × 0.01 × π/180` → rad
- 速度 `度/s × 0.1 × π/180` → rad/s
- 力矩 `A × 0.01 × KT` → Nm
- Kp `UINT16` 直接是 0~500
- Kd `UINT16 / 100` → 0~5.00

`PMAX / VMAX / TMAX / KT` 在固件 `gMotorCfg[17]` 里按每台电机填写。

### 5.2 上行：反馈帧（电机 → MCU）

标准帧，DLC = 8，按达妙 MIT 格式解码：

| 字节 | 内容 |
|---|---|
| `D[0]` | 电机 ID |
| `D[1]` | `ERR[3:0] << 4 \| pos[15:12]` |
| `D[2]` | `pos[11:4]` |
| `D[3]` | `pos[3:0] << 4 \| vel[11:8]` |
| `D[4]` | `vel[7:0]` |
| `D[5]` | `tor[11:4]` |
| `D[6]` | `tor[3:0] << 4 \| Tmos[11:8]` |
| `D[7]` | `Tmos[7:0]` |

解码后按第 3.2 节的 10 B 槽写回 `0x6000`，位置换成 0.01°、速度换成 0.1°/s。

## 6. 对象字典与 EEPROM

| 对象 | 长度 | 内容 | 映射对象 |
|---|---|---|---|
| `0x7000` | 176 B | 控制字 + 序列号 + 17 轴命令 + 填充 | `0x1600`（176 项） |
| `0x7050` | 20 B | U1..U20 | `0x1605`（20 项） |
| `0x6000` | 204 B | IMU + 17 轴反馈 + VT + end | `0x1A00`（204 项） |
| `0x60F0` | 212 B | R1..R212 | `0x1A0F`（212 项） |

`0x1C12`（SM2 分配）= 2 个：`0x1600` + `0x1605`
`0x1C13`（SM3 分配）= 2 个：`0x1A00` + `0x1A0F`

**EEPROM 不需要改**：SII 里只有 SM2=196 / SM3=416，没有 PDO 映射类别；
本次改动只是把 196 B 内部重新切分，总长不变。

ESI 文件：`User/SSC/SSC_Device.xml`（SSC 工具生成，主站侧导入）。

| 40 | raw_acc[3] | int16 | 原始 LSB |
| 46 | raw_gyro[3] | int16 | 原始 LSB |
| 52 | temp | u16 | 预留 |

| 56 | alstat | u16 | 0x0008 = OP |

## 9. 无电机时的模拟

`WHW_IRQN.c` 顶部：

```c
#define MOTOR_SIM_ENABLE   1   /* 接上真实电机后改成 0 */
```

打开后 TIM7 每 1 ms 给 17 个反馈槽填合成数据：三角波、周期 2 s、
幅值 20.00~37.00°、每轴相位错开 `轴号×137 ms`；速度为三角波斜率
（由相位直接算出，避免主站拷贝与 ISR 改写撞车产生撕裂值）；
状态字恒为「使能 + 反馈有效」。

走的是和真实 CAN 反馈完全相同的编码路径，所以主站侧不需要任何切换。

## 10. 已知限制

### 10.1 CAN 带宽

| 总线 | 轴数 | 当前配置 | 每周期帧数* | 1 kHz 可行性 |
|---|---|---|---|---|
| CAN1 | 7 | 经典 CAN 1 Mbit/s | 14 | **不可行**（约 1.67 ms） |
| CAN2 | 7 | FD-BRS 1M/5M | 14 | 可行（约 0.7 ms，70%） |
| CAN3 | 3 | 经典 CAN 1 Mbit/s | 6 | 勉强（约 0.71 ms，71%） |

\* 7 条命令 + 7 条反馈，经典 CAN 8 字节帧约 119 µs，FD-BRS 约 50 µs

要让 CAN1 跑 1 kHz，需要改 FD-BRS（前提是电机支持），或把控制率降到 500 Hz。

### 10.2 SPI

- LAN9252 SPI 模式上限 40 MHz，当前已跑在 40 MHz（`PLL3P 80MHz /2`）。
- 实测 40 MHz 正常，50 MHz / 80 MHz 均失败（BYTE_TEST 回读错误）；
  读指令是 `FASTREAD (0x0B)`，不是指令档位问题，是链路时序/板级极限。

### 10.3 其他

- 位置量程 `INT16 × 0.01°` = ±327.67°，超过一圈的关节需要改编码。
- `0x7050` 只剩 20 B，RMUI 扩展用量不能超过 20 B。
- 主站侧偶发 `WKC=0`（单帧丢失），与固件版本无关，是主机/环境抖动。
